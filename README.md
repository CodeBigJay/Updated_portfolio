## Technology

The application documentation describes:

- React 19 and TypeScript frontend built with Vite
- Java 21 and Spring Boot REST backend
- Spring Data JPA and PostgreSQL
- JWT-based admin authentication
- Docker Compose for local multi-service development

## What the project demonstrates

- Full-stack application structure
- Frontend-to-backend REST communication
- Relational database integration
- Authentication and protected administrative operations
- Containerised local development
- Dynamic portfolio content management

## Before running or deploying

Follow the application README for the current setup instructions. Use private environment variables for secrets and replace all development-only credentials before any public deployment.

The live website and the source repository are separate: use the live link to view the deployed portfolio and the nested source folder to inspect its implementation.
